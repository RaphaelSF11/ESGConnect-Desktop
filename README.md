O ESGConnect é um projeto web criado para praticar e consolidar os conhecimentos adquiridos no curso de front-end da Alura. Ele serve como um painel de tecnologia simples, demonstrando a estrutura básica de um site com HTML e a estilização com CSS.

## Funcionalidades

- Estrutura HTML bem definida.
- Estilos CSS aplicados para uma apresentação visual agradável.
- Código organizado e comentado para facilitar a compreensão.

## Como Visualizar o Projeto

Para visualizar o projeto, siga os passos abaixo:

1.  Clone o repositório:

    ```bash
    git clone https://github.com/RaphaelSF11/ESGConnect.git
    ```
2.  Navegue até a pasta do projeto:

    ```bash
    cd ESGConnect
    ```
3.  Abra o arquivo `index.html` no seu navegador.
